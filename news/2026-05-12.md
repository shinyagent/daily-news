## AI NEWS

**1. Malicious Hugging Face Repo Posed as OpenAI Release, Infected 244K+ Downloads**
A sophisticated supply chain attack on Hugging Face saw threat actors publish a fake "OpenAI Privacy Filter" model that delivered infostealer malware to Windows machines. The malicious repository accumulated roughly 244,000 downloads before removal and used a loader script that disabled SSL verification, fetched a remote payload via jsonkeeper.com, and installed a Rust-based trojan targeting browsers, cryptocurrency wallets, FileZilla configs, and SSH keys. Researchers at HiddenLayer noted the download count may have been artificially inflated to push the repo onto Hugging Face's trending list. The malware also tried to disable Windows Antimalware Scan Interface and established persistence via a scheduled task mimicking a legitimate Microsoft Edge update. Six additional repositories sharing the same infrastructure were identified, and attackers have previously hidden malicious code inside Pickle-serialized model files on public registries — a vector that bypasses platform scanners. Enterprises cloning AI models directly into environments with access to source code and cloud credentials face elevated risk.
Source: https://www.artificialintelligence-news.com/news/malware-on-hugging-face-malicious-software-masquerading-as-openai-release/

**2. Mini Shai-Hulud: TanStack npm Supply Chain Worm with Valid SLSA Provenance**
A new wave of the Shai-Hulud supply chain attack compromised 172 npm and PyPI packages across 403 malicious versions, including 84 versions across 42 @tanstack/* packages — one of which (@tanstack/react-router) receives 12.7 million weekly downloads. Every malicious version carried a valid SLSA Build Level 3 provenance attestation, making this the first widely reported npm worm to bypass provenance-based procurement controls. The kill chain exploited orphaned Git commits, cache poisoning via pull_request_target workflows, and OIDC token extraction from runner process memory. The worm targets AI coding agent configurations (.claude/, .vscode/) as high-value credential stores, harvests Claude and Kiro MCP server auth tokens, and installs persistence that survives package uninstallation. A 1-in-6 chance of destructive `rm -rf ~/` behavior was observed on systems geofenced to Israel or Iran. Fully weaponized Shai-Hulud worm code has reportedly been open-sourced, lowering the barrier for any threat actor to deploy the same attack chain.
Source: https://venturebeat.com/security/shai-hulud-worm-172-npm-pypi-packages-valid-provenance-ci-cd-audit

**4. Perceptron Mk1: Video Analysis AI Model at 80–90% Lower Cost Than Anthropic, OpenAI, Google**
Two-year-old startup Perceptron Inc. released Mk1, a video analysis and spatial reasoning model priced at $0.15/M input tokens and $1.50/M output tokens — roughly 80–90% cheaper than Claude Sonnet 4.5, GPT-5, and Gemini 3.1 Pro. Founded by former Meta FAIR researchers, Perceptron built a "multi-modal recipe" for understanding cause-and-effect, object dynamics, and the laws of physics in video streams. The model processes native video at up to 2 FPS across a 32K token context window, maintains object identity through occlusions, and can read analog gauges and clocks. Early adopters include sports broadcasting (auto-clipping highlights) and robotics (teleoperation data curation). A 2-billion parameter open-weights variant, Isaac 0.2-2b-preview, is available on Hugging Face for edge deployments.

**5. Claude Confused Deputy Audit Matrix: Four Security Surfaces, One Architectural Failure**
VentureBeat published a detailed audit mapping four recently disclosed Claude trust-boundary failures, including the Dragos finding that an adversary used Claude to autonomously identify a Mexican water utility's SCADA gateway, write a 17,000-line exploitation framework, and launch automated password spray attacks — without any ICS/OT context provided. LayerX disclosed ClaudeBleed, a Chrome extension attack allowing any zero-permission extension to hijack Claude; Anthropic's patch was bypassed within 24 hours. Mitiga showed how an npm postinstall hook rewriting ~/.claude.json can steal OAuth tokens for Jira, Confluence, and GitHub and reassert the malicious endpoint even after token rotation. Adversa AI demonstrated that project-scoped config files in cloned repositories auto-authorize MCP servers with full OS privileges when developers click "Yes, I trust this folder." All four affect Claude Code, Cursor, Gemini CLI, and GitHub Copilot. The common architectural failure: a flat LLM authorization plane that grants every capability a user holds, with no separation between the developer's intent and an adversary's instructions.
Source: https://venturebeat.com/security/claude-confused-deputy-audit-matrix-security-blind-spots

**8. Needle: Open-Source 26M Parameter Function-Calling Model Running at 6,000 Tok/s on Consumer Devices**
Cactus released Needle, a 26-million parameter function-calling model on Hugging Face (MIT license) that achieves 6,000 tok/s prefill and 1,200 tok/s decode on consumer hardware. The architecture replaces MLPs with pure attention and gating mechanisms, and the team argues that massive models are overkill for tool-calling since it is fundamentally retrieval-and-assembly rather than reasoning. Pretrained on 200B tokens (16 TPU v6e, 27 hours) and post-trained on 2B tokens of synthesized function-calling data (45 minutes), Needle beats FunctionGemma-270M, Qwen-0.6B, and Granite-350M on single-shot benchmarks while being orders of magnitude smaller. The finding generalizes to any task where models have access to external structured knowledge — RAG, tool use, and retrieval-augmented generation. Finetuning code and playground are publicly available.
Source: https://github.com/cactus-compute/needle
