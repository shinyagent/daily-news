**2. OpenAI Launches ChatGPT Work — an Autonomous AI Agent for the Workplace**
Summary: OpenAI introduced ChatGPT Work, a cloud-based AI agent that autonomously executes multi-step tasks across email, Slack, calendars, and code repositories. Powered by GPT-5.6, it can produce finished documents, spreadsheets, and presentations — marking OpenAI's clearest repositioning of ChatGPT from chatbot to workplace platform. **3. GPT-5.6 Family Arrives: Luna, Terra, and Sol**
Summary: OpenAI released GPT-5.6 in three sizes — Luna ($1/$6 per M tokens), Terra ($2.50/$15), and Sol ($5/$30) — all with million-token context windows and 128K max output tokens. On the Agents' Last Exam benchmark, Sol scored 53.6, beating Claude Fable 5 by 13.1 points. However, Fable 5 still crushed the GPT-5.6 family on SWE-Bench Pro (80% vs Sol's 64.6%), with OpenAI publishing a critical audit of that benchmark shortly after.
Source: https://simonwillison.net/2026/Jul/9/gpt-5-6/

**8. Google's TabFM — Zero-Shot Foundation Model for Tabular Data That Skips Per-Dataset Training**
Summary: Google Research released TabFM, a foundation model that treats tabular prediction as an in-context learning problem, generating predictions for completely unseen tables in a single forward pass. This could reduce time-to-production from weeks of data pipeline engineering to a single API call — a significant breakthrough for the 80% of business data that lives in tabular formats.
Source: https://venturebeat.com/technology/googles-tabfm-skips-per-dataset-training-and-still-predicts-on-tables-its-never-seen

**9. Tencent Releases Hy3: 295B-Parameter Open Source MoE Model**
Summary: Tencent released Hy3, a 295B-parameter Mixture-of-Experts model with 21B active parameters and an Apache 2.0 license. It outperforms similar-size models and rivals flagship open-source models with 2–5x the parameters. The model (598GB full, 300GB in FP8) is available on OpenRouter for free until July 21st and represents a significant new entrant in the open-weight AI race.
Source: https://simonwillison.net/2026/Jul/6/hy3/

**10. "Slopsquatting" — How AI Coding Tools Are Creating a New Software Supply Chain Threat**
Summary: Security researchers have identified "slopsquatting," a novel supply chain attack that exploits LLM hallucinations to inject malicious code. AI coding assistants sometimes generate fictitious package names; attackers register those names and populate them with malware. As developers increasingly rely on AI coding tools, this attack vector presents a serious and growing security risk.
Source: https://venturebeat.com/security/forget-typosquatting-slopsquatting-is-the-software-supply-chain-threat-created-by-ai-coding-tools
