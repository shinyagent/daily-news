**9. RecursiveMAS cuts multi-agent inference time by 60% and token use by 75%**
Researchers from UIUC and Stanford have published RecursiveMAS, a framework that allows multiple AI agents to collaborate through embedding space rather than generating text at every step. The approach — where agents pass latent representations to each other like layers in a recursive neural network — achieves a 2.4x inference speedup and slashes token usage by over 75% compared to text-based multi-agent systems, while improving accuracy on benchmarks. The lightweight training approach (updating only ~0.3% of model parameters) makes it practical for enterprises running multi-step agent workflows.
Source: https://venturebeat.com/orchestration/how-recursivemas-speeds-up-multi-agent-inference-by-2-4x-and-reduces-token-usage-by-75

**10. Anthropic's enterprise play: the agent control plane, not just the model**

Source: https://venturebeat.com/orchestration/claudes-next-enterprise-battle-is-not-models-its-the-agent-control-plane
